==================================================
SUPABASE + NETLIFY ARCHITECTURE
==================================================

IMPORTANT:
Do NOT write directly to Supabase from the browser using sensitive keys.

Use this flow:
Frontend → Netlify Function → Supabase

1. Frontend submits final exam attempt to:
`/.netlify/functions/submit-attempt`

2. Netlify Function uses environment variables:
- SUPABASE_URL
- SUPABASE_SERVICE_ROLE_KEY
- SITE_NAME
- EMAIL_TO (optional)
- EMAIL_FROM (optional)

3. Netlify Function inserts into Supabase table(s)

4. Frontend receives JSON success/failure

5. Optional:
- add a second Netlify function `get-attempts.js` for admin reporting
- this can read submissions securely
